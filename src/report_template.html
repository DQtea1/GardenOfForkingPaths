⚠ Le vrai problème : double dipping

Les clusters sont définis à partir de l’expression, puis la différence d’expression est testée entre ces mêmes clusters. Les p-values de DESeq2 sont donc mécaniquement anti-conservatives : les groupes ont précisément été construits pour maximiser cette séparation. Même sur des données purement nulles, cette procédure peut produire des milliers de gènes « significatifs », puis des pathways GSEA apparemment très enrichis. Ces résultats doivent être lus comme une caractérisation descriptive, pas comme une validation statistique indépendante.
